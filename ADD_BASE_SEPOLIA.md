# Adding Base Sepolia to MetaMask

## Quick Add (Recommended)

Visit this link while MetaMask is installed:
https://chainlist.org/chain/84532

Click "Add to MetaMask" button.

## Manual Add

1. Open MetaMask
2. Click on the network dropdown at the top
3. Click "Add Network" or "Add a network manually"
4. Enter the following details:

```
Network Name: Base Sepolia
New RPC URL: https://sepolia.base.org
Chain ID: 84532
Currency Symbol: ETH
Block Explorer URL: https://sepolia.basescan.org
```

5. Click "Save"

## Get Testnet ETH

Once added, you need testnet ETH for gas fees:
- Visit: https://www.coinbase.com/faucets/base-ethereum-goerli-faucet
- Or: https://faucet.quicknode.com/base/sepolia

## Test Your Setup

1. Go to http://localhost:3000
2. Login with "user", "lp", or "admin"
3. Click "Connect to Wallet"
4. Select MetaMask from the wallet options
5. Approve the connection in MetaMask
6. Switch to Base Sepolia network when prompted

## Troubleshooting

**Problem: "Wrong Network" error**
- Solution: Manually switch to Base Sepolia in MetaMask

**Problem: Can't see "Connect to Wallet" button**
- Solution: Make sure you're logged in (use "user", "lp", or "admin" as username)

**Problem: MetaMask doesn't pop up**
- Solution: Check if MetaMask is locked, or try clicking the extension icon

**Problem: Transaction fails**
- Solution: Ensure you have testnet ETH in your wallet for gas fees
